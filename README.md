# 小喵掌机 · 背单词固件

给学而思小喵掌机（ESP32 + ST7735 160×128 + 6 键 + 无源蜂鸣器 + WiFi）写的独立背单词固件。
内置人教版 PEP **小学三年级起点 → 高中选择性必修** 共 20 册、**5211 个去重单词**（英文 / 音标 / 中文释义），
全部烧进 Flash，**不依赖 TF 卡**。

![界面预览](preview/preview.png)

> 功能一览：**大字号专注界面**（英文 24px / 中文释义 16px）、**五种单词游戏**（单词闯关 30 关 + 配对消消乐 +
> 字母重组 + 猜单词 + 单词接龙）、**静音时的 I2C 灯光反馈**、**WiFi 联网**（NTP 对时 + 网页词库管理）、
> **8 种可配置屏保**、**状态栏常显时间与电量**、**SM-2 记忆调度**，
> 自检 **31/31 通过**；真机全功能测试 **109/109 通过**（COM3 实机，`tools/test_full.py`）。

---

## 一、硬件与引脚

与社区 Retro-Go 移植完全一致，本机 COM3 实测通过（ESP32-D0WD，4MB Flash，**PSRAM 4088KB 可用**）。

| 功能 | GPIO |
|---|---|
| 上 / 下 / 左 / 右 | 2 / 13 / 27 / 35 |
| A / B | 34 / 12 |
| 屏幕 CS / DC / MOSI / CLK / MISO | 5 / 4 / 23 / 18 / 19 |
| TF 卡 CS（保持高电平离线） | 22 |
| 无源蜂鸣器 | 14 |
| I2C SCL / SDA（马达-LED 控制器 0x40，寄存器 0xA0 控灯） | 15 / 21 |

> 注意：ESP32 Arduino 核心的 `Wire.begin()` 签名是 **(sda, scl, freq)**，SDA 在前；传反会扫不到设备。

屏幕无硬件复位脚、无背光控制，走软件复位；MADCTL 默认 `0x60`（与 Retro-Go 一致）。

## 二、按键操作

| 键 | 作用 |
|---|---|
| ↑ ↓ | 移动光标 / 上下翻 |
| ← → | 左右翻页、调整数值 |
| A | 确认 / 显示释义 / 输入 |
| B | 返回上一级 / 拼写界面退格 |

主菜单 12 项：`今日学习 / 快速复习 / 四选一测验 / 拼写练习 / 单词闯关 / 配对消消乐 /
字母重组 / 猜单词 / 单词接龙 / 错词本 / 统计 / 设置`

- **背单词卡片**：A 显示释义 → `←` 判「忘了」、`→` 或 `A` 判「记得」
- **四选一**：↑↓ 选项，A 确认
- **拼写**：方向键在字母盘上移动，A 输入，`←` 退格，`OK` 提交
- **单词闯关**（第 5 项）：见下文
- **配对消消乐**（第 6 项）：方向键选牌，A 翻牌配对（3 列 × 4 行共 12 张牌）
- **字母重组**（第 7 项）：`←→` 选打乱字母，A 填入
- **猜单词**（第 8 项）：7×4 字母键盘，`←→↑↓` 选字母、A 猜；6 条命，猜错判。- **单词接龙**（第 9 项）：用上个词的尾字母开头，选 3 个候选之一
- **错词本**：A 从选中词开始重练；第一项「清空错词本」按两次 A 生效
- **屏保中按任意键** → 立即回到之前的界面。**这次按键被消费掉，不会穿透触发当前界面的功能**
  （修复前自动屏保唤醒时会意外「替你按一下」，在设置里预览屏保甚至永远退不出来）


## 二点五、单词闯关玩法

每天刷关练单词的闯关模式，进度存在设备里（NVS，断电不丢）：

| 规则 | 说明 |
|---|---|
| 关卡 | 共 **30 关**，每关 **10 题**；通关才解锁下一关（第 1 关默认开放） |
| 题型 | 每关三种题型轮换：**英→中**、**中→英**、**音标→英**，全部四选一 |
| 限时 | 每题 **15 秒**，倒计时条变红（剩 5 秒）提示；超时算错 |
| 生命 | **3 条命**（右上角红方块），答错/超时扣 1，扣完挑战结束 |
| 连击 | 连对 2 题起显示「连击 xN」，激励连续答对 |
| 过关 | 答对 **≥8 题** 通关；**星级 = 答对数 − 7**（8/9/10 题 = 1/2/3 星） |
| 词源 | 优先从**已学词**出题，已学词不足自动用启用词册补齐 |
| 调度 | 答题结果**计入 SM-2 记忆调度**——闯关刷题同时推进复习计划，错词自动进错词本 |
| 结算 | 显示星星（■■■）、答对数、最高连击；A 再来一次，B 回选关 |

选关界面：5×6 网格，每格显示关号 + 3 格星级条，未解锁关卡灰显；`←→` 翻页选关。

## 二点六、配对消消乐 & 字母重组

### 配对消消乐（英↔中记忆配对）

每关 12 张牌（6 英文 + 6 中文释义）按 3 列 × 4 行随机摆放，`←→↑↓` 移动光标、A 翻牌：

- 翻开两张：同一单词的英文牌 + 中文牌 → **配对成功消除**（绿色），计入 SM-2 答对
- 配错自动翻开复位，计入答错并进错词本
- 12 张全部消除进入下一关，配对数/尝试次数实时统计

### 字母重组（拼写还原）

显示中文释义和打乱的字母格子，`←→` 选择字母、A 填入：

- 按**原单词字母顺序**填满即判定（填错整词作废，扣 1 条命并重新打乱）
- **3 条命**，连续答对 8 个词通关；每词 +10 分
- 答题结果同样计入 SM-2 调度

两个游戏共用词库（5211 词），与闯关一样在玩的同时推进复习计划。

## 二点七、猜单词 & 单词接龙（新加的两种）

### 猜单词（Hangman）

屏幕上画部分完成的绞架，你要在 6 条命用完前猜出整个单词：

- 7 列 × 4 行的字母键盘，`←→↑↓` 移动、A 猜；**重复按已猜过的字母只"咔"一声，不重复扣命**
- 猜对 → 该字母所有出现位置一次性显示；猜错 → 扣 1 条命并补画一笔绞架
- 全部字母猜出 = 本词过关（得分 `20 + 剩余命数×5`，计入 SM-2 答对），1.3 秒后自动进下一词
- 6 条命用光 → 游戏结束显示答案

### 单词接龙（Chain）

给出当前词的**尾字母**，在 3 个候选词里挑一个以该字母开头的接上去：

- `↑↓` 选候选、A 确认、B 退出
- 接对 → 连击 +1、得分 `10 + 连击×2`，**选中的词成为新的当前词**接着往下接
- 接错 → 连击归零、扣 1 条命（共 3 条），1.5 秒后回到同一词重来；3 条命用光 → 结算页

## 三、功能

1. **今日学习** — 到期复习词（打乱）+ 每日新词（默认 20，可调 10/15/20/30/50）
2. **快速复习** — 只跑到期队列
3. **四选一测验** — 20 题，错词优先出题，答错自动进错词本
4. **拼写练习** — 15 题，看中文拼单词，只挑纯字母词
5. **错词本** — 自动收集、单独重练、一键清空
6. **统计** — 已学/掌握/待复习/错词/连续场次/今日与累计正确率 + 进度条
7. **WiFi** — 扫描并连接、断开、忘记网络、立即对时、手动改时、查看网址
8. **设置** — 选册、每日新词、音效、显示方向、颜色模式、**屏保样式**、**屏保延时**、**电量显示模式**、清空进度

复习调度用简化 **SM-2**：答对 `1→3→×难度系数` 递增（上限 3650 天），答错降难度系数并放回明天，
连续答对 3 次自动移出错词本。

## 四、WiFi 与对时

开机后台自动连接已保存的 WiFi（不阻塞开机），连上后：

| 方式 | 说明 |
|---|---|
| **NTP 自动对时** | 阿里云 / 国家授时中心 / pool.ntp.org，连网即校准 |
| **浏览器访问** `http://xiaomiao.local` | 状态查看、手动改时、**上传 CSV 词库**、**从网址拉取词库**、进度备份/恢复、改 WiFi |

- 没有网络也能用：可在「设置 → 时间设置」手动调时间，进度按日期正常调度
- 时间会定期写入 NVS，掉电重启后时间大致连续
- 词库 CSV 格式：`英文,音标,中文`（音标可留空）

## 五、屏保（8 种，可在设置里选）

数字时钟（**默认**）/ 模拟表盘 / 星空穿越 / 飘雪 / 弹跳方块 / 水波 / 单词轮播 / 猫咪

- 空闲 60 秒自动进入（可调：关闭 / 15s / 30s / 60s / 2min / 5min）

## 六、状态栏

所有界面的标题栏右侧常驻：**电量图标（颜色随电量变化）+ 当前时间 HH:MM**。
未对时时显示 `--:--` 并以高亮色提示。

### 关于电量

掌机**没有电池电压检测电路**，默认走「估算」模式（按使用时长推算，满电约 10 小时）。
可在设置里改为：

- **扩展口**：外接分压电阻到 ADC 脚（默认 GPIO32，可改 32/33/25/26），按电压换算百分比
- **隐藏**：不显示电量
- 设置里可在「标记满电」后归零估算计数

## 六点五、静音时的灯光反馈

设备在 I2C 地址 **0x40** 上有一个马达/LED 控制器（寄存器 `0xA0` 写 1 开灯）。**关掉音效时用它做反馈**：

| 反馈 | 灯节奏 | 原来蜂鸣器写法 |
|---|---|---|
| 按键咔哒 | 闪 1 下（60ms） | `tone(2400, 12)` |
| 答对 | 闪 2 下 | `1568Hz → 2093Hz` |
| 答错 | 急闪 3 下 | `tone(220, 200)` |

调度器是**非阻塞**的：`pulse()` 只登记闪烁计划，`Lights::tick()` 在主循环推进开关，全程不 `delay`，
不会因为灯亮着卡住按键响应。三种节奏分优先级（err > ok > click），高优先级可以直接打断低优先级，
避免连按时出现"灯海"。

自检里第 9c 节会确认 `I2C 灯控 0x40 在线` 且寄存器可写；`i` 命令的 `light=1` 表示在线。
灯不在线也不影响正常使用（所有调用都会静默返回）。

## 七点五、存储机制（改过一轮，值得记一笔）

| 数据 | 放哪 | 为什么 |
|---|---|---|
| 设置（21 词册勾选、每日新词、屏保样式…） | **NVS**（`prefs`） | 只有几百字节，`putBytes` 约 2ms，随时可写 |
| 学习进度（5211 词 × 10 字节 = 54KB） | **裸分区 `prog`**（0x3A0000, 384KB） | 下面那段血泪史 |
| 自定义词库 CSV | **LittleFS 分区 `fs`**（0x390000, 64KB） | 只偶尔写一次，无所谓慢 |

**为什么进度不再用 LittleFS**：原来存 `/prog.bin`，每次答对/答错都想增量写，
但在这块反复擦写的分区上，即使 `r+` + `seek` 只写 10 字节，实测也要 **~1080ms**
（LittleFS 每次写都触发整文件压缩/GC，`setBufferSize(8192)` 也没用）——答一个词卡一秒，体验没法用。

改成裸分区后：**头部扇区**放 magic/version/size，**数据区**是内存里 `WordState[]` 的扁平镜像，
脏词按所属 4KB 扇区聚合，每次只擦写那一个扇区。实测**答 4 题后保存只需 15~17ms**（约 70 倍提速），
且重启后进度完整保留。注意 409 词 × 10 字节 = 4090 字节 ≠ 4096，
所以**必须按字节算扇区归属，不能按"词块"对齐**。

两个坑，改分区表前先看：

1. **`fs` 和 `prog` 必须落在从未被 LittleFS 格式化过的干净偏移**。把原来的 256KB LittleFS 分区缩小后
   挪到老位置会 boot loop——旧超级块里声明的块数比新分区大，`esp_littlefs` 在 mount 时
   `lfs_fs_grow` 断言失败，**根本走不到 `format()` 回退分支**，连日志都来不及打。
2. **`tools/flash.py` 必须按偏移量分别写**（bootloader / 分区表 / app 各写各的）。
   早期版本合并成一个 bin 从 `0x0` 连写，bin 里的 0xFF 间隙会盖掉 0x9000 的 NVS 分区，
   esptool 写前还会擦扇区 —— **每次刷机都丢设置和进度**。

每日计数（`todayNew` / `todayReview` / `todayAnswers` / `todayCorrect`）会在**换日时自动重置**，
并据此推进连续学习天数 `streak`；按 NTP 对时后的「当天」算（未对时则退化成按开机场次算，不影响正常使用）。

## 九、已知限制

- 屏幕只有 160×128：中文释义已裁剪到 15 字内，长释义会自动换行/截断
- 只有无源蜂鸣器，**没有真人发音**（要发音需硬件加 I2S 功放+喇叭）
- 电量是**估算**（硬件无检测电路），要精确请接分压电阻到扩展口 ADC
- 灯光反馈依赖 I2C 0x40 那颗控制器，**不是每台掌机都有**；不在时所有调用静默返回，不影响使用
- 刷了这个固件，掌机上原来的 MicroPython / 学而思课程环境就没了（原厂备份另存，可随时刷回）

### 串口的一个小坑

GD32 串口桥在**刚打开端口那一两秒**不稳：首条命令可能被吞，甚至会把毛刺字节（如 `0x00`）
拼进命令行，让整条命令被当成空行**静默丢弃**（现象是"命令发出去毫无反应，但别的命令照常"）。
固件侧已经只接收可打印 ASCII（收到非打印字节会打印 `[rx] 丢弃非打印字节 0x..`），
测试脚本侧也有热加重试兜底。手动调试时遇到"第一条没反应"，重发一次即可。
